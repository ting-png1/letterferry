# 渡信 · LetterFerry

**把消息渡到另一端：微信私聊 ↔ 本地 Node.js ↔ 你指定的 ChatGPT 网页对话。**

一个面向 Windows + Edge 的本地实验项目。它使用你自己登录的 ChatGPT 网页，不需要 OpenAI API Key；微信端需要你自行完成获许可的机器人二维码登录与一对一配对。不是腾讯、微信或 OpenAI 官方产品。

> **Developer Preview / 开发者预览。** 代码可供学习、测试与二次开发，但还不是开箱即用的公共服务。请先看完安全须知，再决定是否连接真实账号。

## 当前能做什么？

| 能力 | 当前状态 |
| --- | --- |
| 本地启动 ChatGPT Web Host，手动绑定一个 ChatGPT 对话 | 已实现 |
| 从一个明确配对的微信私聊接收文字、送入 ChatGPT 并回传 | 经过一次端到端人工验收；其他环境需自行验证 |
| 30 分钟前台会话，人工确认后运行 | 已实现；不保证各账号都能使用 |
| 图片下载、解密、加密收据、去重、浏览器附件预检 | **离线实验通过，未接入正式图片收发** |
| 混合文字与图片批次处理、图片任务持久化、本地认证二进制传输 | **离线实验通过，默认关闭** |
| 无人值守服务、多人聊天、群聊、语音、自动图片回复 | **未支持 / 未验证** |

当前 0.4.3 候选版的本机离线测试：**333/333 项通过**。模拟测试不等于你自己的微信账号、浏览器上传和远端模型实际收图已通过。

## 工作方式

```text
你的微信 Bot 私聊
  ↓ 仅限明确配对的一位发送者
本机 Weixin Bridge (Node.js, SQLite)
  ↓ 浏览器 Host (127.0.0.1)
Edge 扩展 → 手动指定的 ChatGPT 对话
  ↓ 只从当前对话读取回复
本机 Bridge → 你的微信私聊
```

**不接管所有私人聊天，不扫描群聊，不向陌生人自动回复。** 浏览器目标必须人工绑定。出现重复提交、断线或送达结果不明时，系统会中止自动重试，等待人工复核。

## 先运行安全的离线测试

需要 **Windows 10/11、Node.js 22.13+、npm 和 Microsoft Edge**。建议先在没有任何真实微信连接的状态下运行：

```powershell
npm ci
npm test
npm run check
npm run demo
```

这些命令仅运行模拟数据与本地测试，**不会登录微信或向 ChatGPT 发送消息**。

## 想接上自己的微信和 ChatGPT？

请看 **[朋友安装与验收指南](docs/FRIEND_SETUP.md)**。基本顺序是：

1. 在 Edge 登录自己的 ChatGPT，安装本地未打包扩展，手动绑定**唯一**目标对话。
2. 启动本机 Web Host，设置由本机生成的专用密钥。
3. 明确同意后，按 CLI 提示进行微信机器人二维码登录与单人私聊配对。
4. 先单次接收、检查 ChatGPT 回复，再人工确认发送；通过后才考虑短时前台会话。
5. 任一步出现未知状态、账号限制或重复发送风险就停下来，**不要盲目重试**。

图片链路现在仅供开发者离线阅读和测试，**不要当作已启用的微信图片聊天功能**。

## 安全与隐私

- 所有真实凭据、绑定信息和 SQLite 运行数据仅放在本机 `data/` 下，**不得提交到 GitHub**。
- 不要在 issue、截图、小红书、日志里公开二维码、密钥、聊天正文、`context_token`、账号标识。
- 使用前核对微信／ChatGPT 的服务条款与账号资格，项目不保证长期兼容或绕过任何平台限制。
- 代码不会替你自动授权登录、自动越过人机验证或自动重试结果不明的发送。
- 暂不建议在主力微信账号上直接进行未经人工监督的长时间运行。
- 具体边界见 [SECURITY.md](SECURITY.md) 与 [协议兼容说明](docs/PROTOCOL_AND_FEASIBILITY.md)。

## 技术组成

Node.js ESM、`node:sqlite`、Windows DPAPI / AES-256-GCM、Edge Manifest V3 扩展，以及可人工确认的 iLink/Weixin Bot 协议接入。源代码以少依赖、显式权限和默认关闭为原则。
